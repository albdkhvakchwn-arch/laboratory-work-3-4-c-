# Объединённая лабораторная работа 03–04 (C#)

Консольное приложение объединяет требования Project 03 и Project 04: токенизацию русских и английских текстов, операции над предложениями и словами, экспорт XML и построение конкорданса.

## Структура классов

- `Program` — запуск приложения и загрузка исходного файла.
- `Text`, `Sentence`, `Token`, `Word`, `Punctuation` — модель текста и операции над ней.
- `TextParser` — разбор исходного текста на предложения и токены.
- `ConcordanceBuilder` — подсчёт слов и номеров строк.
- `TextAnalyzerConsole`, `ConsoleInput` — меню и ввод пользователя.
- `StopWordProvider`, `TextXmlExporter` — загрузка стоп-слов и XML-экспорт.

## Запуск

```bash
dotnet run --project Lab03_04.csproj
```

По умолчанию откроется `sample.txt`. Можно передать путь к другому тексту:

```bash
dotnet run --project Lab03_04.csproj -- путь/к/файлу.txt
```

## Пункты меню

1. Сортирует предложения по возрастанию числа слов.
2. Сортирует предложения по возрастанию длины строки предложения (в символах).
3. Находит неповторяющиеся слова заданной длины в вопросительных предложениях.
4. Удаляет слова заданной длины, начинающиеся с согласной буквы.
5. Заменяет слова заданной длины в выбранном предложении указанной подстрокой.
6. Удаляет русские, английские или оба набора стоп-слов. Списки можно редактировать в `Data/stopwords_ru.txt` и `Data/stopwords_en.txt`.
7. Сериализует текущий объект `Text` в XML через `System.Xml.Serialization`.
8. Строит конкорданс: слова без учёта регистра в алфавитном порядке, частота вхождений и уникальные номера исходных строк.

В конкордансе частота считает каждое вхождение, а номер строки выводится один раз, даже если слово несколько раз встречается на этой строке.
